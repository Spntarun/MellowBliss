# Mellow Bliss — Organic Self-Care

A modern, responsive landing page for Mellow Bliss, featuring organic self-care and beauty products.

## Features

- **Fluid Modern Design**: Soft pastel aesthetics, glassmorphic navigation, and organic animations.
- **Responsive Layout**: Optimized for desktop, tablet, and mobile screens.
- **Interactive Experience**: Hero video background, product showcase cards, and instant contact options.
- **Pure Web Technologies**: Lightweight vanilla HTML, CSS, and JavaScript with no external build step required.

## Getting Started

Simply open `index.html` in any modern web browser or serve it via a local development server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve .
```
